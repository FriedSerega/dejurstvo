# Дежурный на неделе

Расширение для Chrome, которое показывает в углу страниц SBIS/SABY, дежурите ли вы на этой неделе по графику из Google Sheets.

## Что умеет

- Показывает компактную плашку «Дежурный», если вы дежурите.
- Раз в день раскрывает карточку с неделей, группой и записью из графика.
- Предупреждает, если график недоступен, пустой или в нём нет текущей недели.
- Красным предупреждает, если неделя есть, но дежурный в вашей группе не указан.
- Меняет значок на иконке расширения: `!` — вы дежурите, `?` — есть проблема с графиком.
- Работает без перезагрузки страницы: если данные в таблице изменились, плашка обновится сама.

## Установка

Расширение устанавливается вручную, без Chrome Web Store.

1. Скачайте репозиторий: **Code → Download ZIP** и распакуйте архив.
2. Откройте `chrome://extensions`.
3. Включите **Режим разработчика**.
4. Нажмите **Загрузить распакованное** и выберите папку `dezhurstvo`.
5. При первом запуске откроется окно настроек.

## Первый запуск

Встроенного графика нет — расширение попросит указать вашу таблицу.

1. Откройте график дежурств в Google Sheets.
2. Скопируйте ссылку из адресной строки браузера.
3. Вставьте её в блок **«Ссылка на график»**.
4. Укажите **ФИО** так, как оно записано в таблице.
5. Укажите **группу** — это обязательное поле.
6. Нажмите **«Сохранить и проверить»**.

Пока ФИО и группа не заполнены, расширение ничего не показывает на страницах SBIS/SABY.

Ссылка нужна один раз. Потом её можно поменять в том же окне, если график перенесли в другую таблицу.

## Настройка

### ФИО

Обязательное поле. Укажите фамилию и инициалы или полное имя — как в таблице. Регистр, точки и лишние пробелы не важны.

### Группа

Обязательное поле. Выберите название группы из подсказок или введите его так, как оно записано в таблице. Без группы расширение не сможет определить, где искать вашего дежурного.

### Ссылка на график

Подходит обычная ссылка на таблицу Google Sheets вида `docs.google.com/spreadsheets/d/...`.

Важно: таблица должна быть доступна по ссылке. В Google Sheets откройте **Настройки доступа** и выберите **«Все, у кого есть ссылка»**. Расширение читает график анонимно и не получает доступ к вашему аккаунту Google.

Если таблица закрыта, расширение покажет «График недоступен» и не сможет прочитать данные.

## Поведение плашки

- **Пилюля** «Дежурный» висит в правом нижнем углу, пока вы дежурите.
- **Карточка** с подробностями разворачивается один раз в день и сама сворачивается через несколько секунд.
- Нажмите на пилюлю, чтобы снова открыть карточку.
- **×** скрывает плашку до следующего дня.
- Пока ФИО и группа не заполнены, плашки нет.
- Если вы не дежурный, плашки нет.
- Если ФИО и группа заполнены, но ссылка на график ещё не указана, в углу висит пилюля **«Нет ссылки»** — нажмите на неё, чтобы открыть настройки.

Плашка работает только на:

- `online.sbis.ru`
- `online.saby.ru`
- `inside.saby.ru`
- `inside.sbis.ru`

## Если график изменился

- **Перенесли на другую вкладку той же таблицы** — расширение найдёт нужную неделю само.
- **Создали новую таблицу** — вставьте новую ссылку в окне настроек.
- **Удалили данные из таблицы** — плашка покажет «В графике нет данных».
- **Оставили пустую ячейку на текущей неделе** — плашка красным предупредит: «В расписании не заполнен дежурный!».
- **Закрыли доступ или удалили файл** — плашка покажет «График недоступен» и подскажет проверить ссылку.

## Данные

- ФИО, группа и ссылка на график хранятся только в вашем браузере.
- Расширение не отправляет их на сторонние серверы.
- Расширение только читает график и ничего в него не записывает.

## Ограничения

- Нужна таблица Google Sheets с доступом по ссылке.
- Расширение не умеет работать с приватными таблицами без публичного доступа.
- Для отображения плашки нужен один из сайтов SBIS/SABY из списка выше.
